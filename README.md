## 🧠 About

**Quizora** is a full-stack AI-powered learning and quiz platform built to make learning more interactive, personalized, and engaging.

Users can generate quizzes using AI, create quizzes from documents, practice concepts, receive intelligent hints and explanations, track their learning progress, maintain streaks, earn achievements, and compete through leaderboards.

The platform also includes dedicated functionality for teachers to create and manage quizzes and monitor learner performance.

> 🤖 **AI Generation Status:** AI-powered quiz generation is temporarily unavailable because the current AI usage limit has been reached. Existing quizzes, practice features, progress tracking, achievements, and other learning functionality remain available.

## ✨ Features

### 🤖 AI-Powered Quiz Generation

- Generate quizzes from any topic
- Choose difficulty levels
  - 🟢 Easy
  - 🟡 Medium
  - 🔴 Hard
- Customize the number of questions
- Add custom quiz instructions
- Generate questions, options, answers, and explanations
- Validate AI-generated quiz data before saving

### 📄 Document-to-Quiz

Turn your learning material into quizzes.

Supported formats include:

- 📕 PDF
- 📄 TXT
- 📝 Markdown
- 📚 Text-based study material

Upload your content and Quizora extracts the information and generates questions based on it.

### 🧠 AI Learning Assistant

Get additional help while learning:

- 💡 AI hints
- 📖 Detailed explanations
- 🔍 Similar questions
- 🎯 Weak-topic practice
- 🧩 Concept-focused learning
